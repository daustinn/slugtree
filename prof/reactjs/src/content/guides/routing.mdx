# Routing

Slugtree automatically maps your directory hierarchy into clean, nested URL slugs.

## Folder Mapping

Folders create parent nodes with their own slug chains.

### Index Files

An `index.mdx` file inside a folder represents the root page of that directory.

### Nested Slugs

Nested subfolders produce structured paths such as `/docs/guides/routing`.
