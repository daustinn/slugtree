# Configuration

You can customize content directories, base paths, and output destinations.

## Plugin Options

- `contentDir`: The directory containing MDX files (default: `./src/content`).
- `outputDir`: Where to store generated metadata (default: `.slugtree`).
- `basePath`: The prefix for all documentation URLs (default: `/docs`).

## Custom Frontmatter

You can define custom fields in frontmatter like `title`, `description`, `icon`, `category`, and `order`.
