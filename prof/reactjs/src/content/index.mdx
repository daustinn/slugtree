# Introduction

Slugtree is an agentic, zero-configuration content tree builder and documentation metadata generator for MDX.

## Overview

Slugtree scans your content directory, builds hierarchical trees, extracts frontmatter, parses table of contents, and creates navigation structures.

### Key Features

- Fast compilation and indexing
- Zero configuration required
- Real-time Vite Hot Module Replacement
- Built-in React hooks and server utilities
