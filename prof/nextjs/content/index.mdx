# Introduction

Slugtree is an automated content hierarchy and navigation tree builder designed for modern documentation systems.

## Key Features

- **Zero Config**: Scans your content directory automatically.
- **Hierarchical Routing**: Generates nested tree structures with breadcrumbs, pagination, and TOC.
- **Blazing Fast**: Instant HMR and in-memory caches.

## Architecture

Slugtree processes your `.mdx` files into structured JSON representations consumable on both server and client components.
