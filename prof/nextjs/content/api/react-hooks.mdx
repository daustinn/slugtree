# React Hooks

Hooks available from `slugtree/react` for interactive client layouts.

## `useSearchContent(query)`

Performs instant client-side full-text search across titles, headings, and markdown content.

## `useNodeBreadcrumbs(slug)`

Generates breadcrumbs trail from root to the active page.

## `useNodePagination(slug)`

Retrieves previous and next page items for documentation pagination.
