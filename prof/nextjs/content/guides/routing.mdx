# Routing & Navigation

Slugtree maps your directory structure directly into nested URL slugs.

## Slug Generation Rules

- `index.mdx` maps to the root of its folder.
- File names like `my-page.mdx` become `/my-page`.
- Subfolders create nested segments like `/guides/advanced/middleware`.
