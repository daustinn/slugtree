---
title: usePageNodes
description: Returns only page-type NodeData from the client context.
---

Client hook equivalent of `getPageNodes()`. Returns a flat `NodeData[]` of every navigable page (where `type === 'page'` or a folder with `href !== undefined`).

```tsx
'use client'

import { usePageNodes } from 'slugtree/react'

export default function AllPages() {
  const pages = usePageNodes()

  return (
    <ul>
      {pages.map((page) => (
        <li key={page.href}>
          <a href={page.href}>{page.frontMatter.title}</a>
        </li>
      ))}
    </ul>
  )
}
```

## Return value

Returns `NodeData[]` containing only navigable page-like entries.

For all nodes including pure folders, use [`useAllNodes()`](/docs/use-all-nodes). For custom filtering, use [`useFindNodes()`](/docs/use-find-nodes).

Must be used inside a component wrapped by `SlugtreeProvider`.
