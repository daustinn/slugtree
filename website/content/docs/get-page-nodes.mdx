---
title: Get Page Nodes
description: Returns all page-type nodes, excluding folders and labels.
---

Returns a flat `NodeData[]` of every navigable page node (where `type === 'page'` or a folder where `href !== undefined`). The primary use case is generating sitemaps and feed files.

```ts
import { getPageNodes } from 'slugtree'

const pages = getPageNodes()
```

## Return value

Returns `NodeData[]` containing only navigable page-like entries. The order matches the tree traversal order from `getAllNodes()`.

## Usage

### Generating a sitemap in Next.js

```ts
import { getPageNodes } from 'slugtree'

export default function sitemap() {
  return getPageNodes().map((page) => ({
    url: `https://example.com${page.href}`,
    lastModified: new Date()
  }))
}
```

### Counting pages

```ts
import { getPageNodes } from 'slugtree'

const pageCount = getPageNodes().length
```

For all nodes including pure folders, use [`getAllNodes()`](/docs/get-all-nodes). For custom filtering conditions, use [`findNodes()`](/docs/find-nodes). For client components, use [`usePageNodes()`](/docs/use-page-nodes).
